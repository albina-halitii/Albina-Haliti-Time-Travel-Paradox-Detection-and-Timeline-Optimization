# Albina-Haliti-Time-Travel-Paradox-Detection-and-Timeline-Optimization

**About the Project**

This project is developed in C++ and focuses on detecting time travel paradoxes in a timeline of historical events.

Events are connected through cause-and-effect relationships. The program analyzes these relationships to identify possible contradictions and explore alternative timelines that can resolve them.

**Project Goals**

- Represent historical events and their dependencies as a directed graph.
- Detect cycles and possible time travel paradoxes.
- Identify events that cause contradictions.
- Find alternative valid timelines.
- Explore ways to resolve paradoxes with minimal changes.
- Analyze the performance of different algorithms.

**Technologies Used**

- *Programming Language:* C++
- *Data Structure:* Directed Graph
- *Tools:* Visual Studio Code, Git, and GitHub

**How It Works**

1. The program receives a set of events and their dependencies.
2. It represents the events as a directed graph.
3. It analyzes the graph to detect cycles and possible contradictions.
4. It explores possible solutions to create a valid timeline.
5. It evaluates the results and measures algorithm performance.

**Algorithms**

The project may use graph algorithms such as:

- *Depth-First Search (DFS):* To explore event dependencies and detect cycles.
- *Topological Sorting:* To determine a valid event order when the graph has no cycles.
- *Cycle Detection:* To identify circular dependencies.
- *Timeline Optimization:* To explore ways of resolving contradictions with minimal changes.
